Virtual Assistant

Full-Stack Voice-Based Assistant Powered by MERN, Gemini & Ollama APIs

🎙️ Voice Interaction: "Gemini + Ollama API engine active"
Problem Being Solved

To connect the backend and frontend seamlessly, and to optimize the assistant's voice and text response time across diverse internet connectivity speeds.

Developed as a comprehensive voice-based interactive assistant using the MERN stack. Integrates Google Gemini API and local Ollama API keys to enable fluid voice interaction, natural language comprehension, and dynamic conversational feedback. Built the entire project from scratch.

Key Contributions:

  • Built the Entire Project: Designed and implemented both the frontend user interface and backend architecture independently.
  • Voice Interaction Flow: Captured user voice input, coordinated speech recognition, and routed prompt payloads to Gemini and Ollama AI APIs.

  • Media & Asset Management: Integrated Cloudinary for media storage and optimized frontend performance with Tailwind CSS styling.

Virtual Assistant (Voice-Based)

MERN Stack • Google Gemini API • Ollama API • Voice Processing

Project Architecture & System Flow

🎙️ Voice Input Microphone & Speech API
➔
⚛️ React Frontend Tailwind CSS UI
➔
⚙️ Node & Express REST Endpoints
➔
🤖 AI Engine Gemini & Ollama APIs

The Challenge & Engineering Problem

Traditional conversational assistants suffer from significant latency when bridging voice transcription, backend logic, and model inference across erratic internet connectivity. The primary objective was to connect the backend and frontend securely while optimizing roundtrip response time based on varying network throughput.

Full Technology Stack

Frontend: React, Tailwind CSS, Web Speech API
Backend: Node.js, Express.js
Database: MongoDB & Mongoose ODM
AI APIs: Google Gemini API, Ollama Local/Remote APIs
Auth & Media: Google OAuth, Cloudinary Storage

Student Contributions

Azmiya built the entire application independently as a complete full-stack portfolio artifact, demonstrating end-to-end technical competence across frontend components, Express routing, external API integration, and database persistence.
